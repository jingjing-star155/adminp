# adminp

HR and compensation management interactive prototype.

## Pages

- [Offer management](https://jingjing-star155.github.io/adminp/#/offers)
- [Compensation structure management](https://jingjing-star155.github.io/adminp/#/payroll/projects)
- [Signing bonus ledger](https://jingjing-star155.github.io/adminp/#/payroll/signing-bonus)
- [Salary change applications](https://jingjing-star155.github.io/adminp/#/hrg/salary-change)

Open index.html locally or visit the published GitHub Pages site. No build or dependencies are required.

This is a frontend prototype with demonstration data. Edits and attachments are stored in the current browser (localStorage / IndexedDB); there is no backend or shared database. Data from a local preview is not uploaded or migrated to the published website. The signing agreement link requires access to the organization's document service.

GitHub Pages publishes the main branch from the repository root.
